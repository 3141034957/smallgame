# 界面与文案规范

改界面、写文案、调整布局前先读这一篇。这里的每一条都来自已经确认过的产品决定，不要凭习惯另起一套。

## 文案

- **按钮就是按钮**：按钮上只放 2–6 个字的动作词（`开始`、`再来一局`、`角色商店`、`登录`、`重连`），不放解释、不放修饰语、不放括号注释。完整语义放进 `aria-label`，无障碍不退化。
- **能删就删，优先于"改短"**：凡是解释游戏怎么玩、复述界面已有信息、提醒注意事项的文字，一律删除，而不是压缩成短句。
- **图标与数字优先**：能用 `✦1,500`、`Lv.3`、`5s` 表达的，不要写成句子。
- 说明文字一句话 ≤ 15 字；宣传语、感叹句、免责声明一律不要。
- 报错只说结果和下一步，不要复述规则（规则在输入框下方已经显示过一次）。

## 信息组织

- **参考《黎明前20分钟》的组织方式**：一个条目就是「图标 + 名称 + 一句话效果」；内容按「系」分组、系内分层递进；跨系组合达成即生效，不占槽位。列表就是干净的列表，没有大段说明。
- **不参考它的视觉风格**：我们坚持乐队主题 —— 草地绿、奶油色、音乐符号、乐器图标。暗色、克苏鲁、霓虹那套不要带进来。

## 手机端布局

目标是模拟原生客户端，**关键页面一屏放下、不需要滚动**：

- 必须单屏：**选择页面**（开始页、角色选择、登录注册）、**游戏页面**（对局 HUD 与叠加层）、**结算页面**。
- 允许滚动：**升级三选一弹窗**、**乐队升级（永久强化）页** —— 这两处内容本来就多。
- 高度链条：外层 `height: 100dvh` + `display: flex; flex-direction: column; overflow: hidden`；中间区 `flex: 1; min-height: 0`；**只有列表区**才 `overflow-y: auto`。不要多层滚动嵌套。
- 字号与间距用 `clamp(最小值, Xdvh, 最大值)` 随屏高自适应；固定 padding / 固定高度会让小屏必然溢出。
- 矮屏（可视高度 < 620px）隐藏次要信息，而不是让页面变长。
- 触控目标 ≥ 40×40；关闭按钮做成 sticky，不要随内容滚走。

## 无障碍

- 按钮文案改短后，`aria-label` 必须保留完整语义。
- `role="alert"` / `role="status"` / `role="progressbar"` 与 aria 数值不要因为改版而丢失。
- 动效遵循 `prefers-reduced-motion`。
