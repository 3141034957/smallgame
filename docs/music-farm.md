# 节拍幸存者

音乐主题的怪潮生存肉鸽，首页和 `#/farm` 进入。一局 60 秒：手机按住拖动、松手停住；电脑鼠标指向前方持续移动，移回角色中心或移出战场停住，也可用方向键 / WASD。镜头跟随角色，地图向四周持续延伸。乐器自动攻击，击败小怪后拾取经验，升级三选一，最终进化武器。

## 战斗规则

- 100 点生命，普通接触伤害 12、重装怪 18、Boss 24；远程弹幕 14、预警砸地 26。受伤后一秒无敌并击退近身怪物。
- 四类音乐怪物：追击音团、快速蝙蝠、保持距离的远程噪音怪、慢速重装音箱。怪物从角色周围 52–68 单位距离的安全环出现，先显示 0.75 秒传送预警，逐渐增加速度、血量和补充数量；普通怪池上限 100，Boss 独立加入。
- 16、34、52 秒出现鼓噪巨兽，追击玩家并锁定位置，红圈预警一秒后砸地。远程攻击使用粉色弹丸，与玩家乐器特效区分。
- 每击败 16 只怪掉落 18 点回血爱心，Boss 掉落 30 点回血并吸取全场掉落。生命不超过上限。
- 能量满后点击「音浪爆发」或按空格，范围攻击、清除已有弹幕与预警、获得一秒保护，并在三秒内加快普通音浪及吸取掉落。
- 生命归零立即失败结算；存活 60 秒通关。两种结局都可提交真实成绩，榜单按清怪分数排名。

参考方向：[暗黑战甲](https://store.steampowered.com/app/2542140/Ketz_Galactic_Overlords/?l=schinese)的怪潮与构筑、[青蛙农场：幸存者](https://store.steampowered.com/app/2479320/Pesticide_Not_Required/?l=schinese)的可爱表现和割草战斗。当前版本保留乐器武器特色，没有加入这些作品的完整装备/经营系统。

## 乐器、芯片、终极形态

芯片是被动强化装备。乐器和芯片均最高 Lv.3，配对满级自动进化，攻击变化即时生效，无需额外抽卡。

| 乐器武器 | 攻击 | 对应芯片 | 终极形态 |
| --- | --- | --- | --- |
| 爆米花鼓 | 怪物间连锁爆破 | 共鸣：扩大普通音浪范围 | 雷霆节拍机：爆破半径增加，连锁伤害翻倍 |
| 回旋吉他 | 周身旋转音刃 | 节拍：提升音浪发射速度 | 星环电吉他：六道音刃，伤害翻倍 |
| 低音大提琴 | 贯穿同列的低音光柱 | 引力：增加掉落吸取距离 | 黑洞低音炮：大范围收割并聚拢全场掉落 |
| 雨落竖琴 | 追击附近怪物的音符雨 | 丰收：增加暴击、金币和经验 | 星雨竖琴：一次追击八只，全场攻击、伤害翻倍 |

三选一按当天种子生成。初始三种乐器每日轮换；后续保留一条已有乐器的进化选项，另外两项随机。每局最多 12 次升级，重开清空本局构筑。金币是本局收益反馈，尚未连接商店或永久养成。四组都可以进化，但不承诺一局能集齐。升级和弹窗期间倒计时暂停；切到后台自动暂停。

音乐为 Web Audio 原创合成伴奏，各乐器获得后加入自己的声部，收割发出音符，未接入 QQ 音乐曲库、账号或歌曲分析。该玩法用于 QQ 音乐互动产品的概念验证。

## 排行榜

`/api/farm/leaderboard?day=YYYY-MM-DD&playerId=...` 查询每日生存榜；`POST /api/farm/score` 接收最多 960 个整数位置帧、升级选择和音浪爆发时刻。少于 960 帧必须在最后一帧真实死亡；拒绝提前截断、死亡后继续帧以及未执行的爆发。服务端使用同一纯规则完整重放，校验移动速度、升级、能量和成绩；忽略客户端金币、经验、装备等统计，每人每日保留最高分，返回前 50 名及个人排名，界面展示前 10 名。

共享既有 SQLite 存储，但通过 `farm:v3:日期`（原 v1、v2 榜单保留隔离） 和独立玩法键隔离旧游戏排行。身份为当前浏览器匿名标识，不是 QQ 登录；回放校验不等于防脚本竞技系统。生产环境仍需根据实际接入补充账户和限流。

## 验证与运行

`npm run build`、`npm run lint`、`npm test`；Node >=22.13。`npm start` 在 3001 同时提供静态页面和 API；开发分别使用 `npm run dev:server` 与 `npm run dev`。

当前全部 132 项测试通过，包含追击差异、接触伤害、无敌/击退、弹幕躲避、Boss 预警、治疗、死亡停止、边缘刷怪、四种武器进化及服务端验证。四个专注构筑固定种子样例均可存活并在 40 秒内进化；站桩样例会死亡。

无限地图浏览器实测从 `(50,76)` 移动到 `(594,-758)`，过程中验证持续方向、中央停住、横屏切换和相机跟随；37.6 秒结束后 18,570 分通过服务端校验与上榜，控制台无错误。上一版固定战场曾验证完整 60 秒通关及两组终极形态，本版自动测试继续覆盖完整局与各武器进化。模拟/自动试玩不代替真实玩家对爽感和难度的反馈。

手机预览截图位于 `output/music-farm/`。本地 QA 服务使用 `/private/tmp/mochi-melody-qa-20261003` 数据，不操作部署服务器。公网版本需另行同步与重启。

## 全屏与流畅度更新

页面直接展示战场，点「开始玩」即开局；竖屏顶部为信息栏、底部为装备和能量，窄横屏把信息和装备移至左右。游戏区域铺满当前视口，世界单位的横纵比例固定为 3.6:4.3，宽屏展示更多周边；视野宽度上限约 250 世界单位，高度约 198。移动输入以角色所在的屏幕中心为参考，每个逻辑帧重新换算到世界坐标，因此保持方向也能持续前进。角色速度设为每逻辑步最多 3 单位（整数帧允许舍入误差），移除原 0–100 战场边界。

战斗计算和成绩回放仍为 16 Hz。角色显示用浮点位置按 requestAnimationFrame 连续推进，最多预测一个逻辑步，怪物、敌方弹丸、旋转音刃与掉落也使用中间状态绘制；显示坐标不写入成绩记录。四种背景图块、怪物、小兔、金币及音符缓存成画布图块，每帧使用 drawImage；尺寸由 ResizeObserver 和 resize 更新，拖动过程中避免反复测量布局。大连锁限制视觉粒子数量，实际伤害和收益保留。

输入参考 [Phaser 的统一输入](https://docs.phaser.io/phaser/concepts/input)：鼠标不要求按键；触摸只跟踪一个手指，捕获指针并处理松手、取消和离开。没有 PointerEvent 的嵌入式浏览器回退至 touch / mouse 事件，触摸监听明确禁止滚动；绘制圆角使用兼容路径。具体设备仍需真机验证，不承诺所有历史浏览器版本。

`#/farm?stats=1` 临时显示绘制 FPS、平均绘制耗时和显示位移更新次数，用于开发排查，正常入口隐藏。当前 Mac Chrome 实战样本约 60–120 FPS、0.4–0.6 ms/帧；包含升级暂停的窗口显示较低计数，手机性能不能据此推断。375×667 竖屏与 844×390 横屏使用浏览器尺寸模拟验证，实际触摸和低端机仍需真机体验。

## 无边界地图与资源管理

地图由稳定的网格坐标生成舞台图块，只枚举当前视野相交的块，不保存走过的完整地图。四种缓存图块复用，背景纹样与音箱地标帮助判断移动；负坐标用向下取整正确拼接。角色保持视野中央，地图、怪物、掉落、弹幕、预警和攻击特效共享世界坐标，血条和受伤边缘效果保持屏幕坐标。

离玩家超过 160 单位的怪物重新投放到周围安全环，保留剩余生命、重新预警，不产生击杀奖励。掉落保留在附近世界坐标，超过 240 单位的遗留掉落回收，最多保留 600 个；屏幕外实体不绘制，弹幕按距离和生命周期清理。地图扩展不会增加缓存图块数。Boss 和敌人碰撞、乐器攻击、负坐标移动均由同一服务端规则重放。

新增测试覆盖长距离和负坐标移动、防瞬移、怪物重投放、传送保护、跨区域弹幕、掉落上限、镜头中心与反向场景移动、可见图块覆盖、持续指针方向及真实远行成绩校验。截图：`output/music-farm/world-mobile.jpg`、`world-negative.jpg`、`world-result.jpg`。
