# 回血与护盾平衡验证

2026-10-06，规则从 `v7-growth` 升至 `v8-recovery`。目标是让永久恢复提供脱离围攻后的缓冲，避免持续受击时自动续命。购买等级、价格与退款保持原样。

## 本次参数

| 来源               | 修改前                            | 修改后                 |
| ------------------ | --------------------------------- | ---------------------- |
| 自动回血安全期     | 4 秒                              | 8 秒                   |
| 自动回血周期       | 6 秒                              | 12 秒                  |
| 五级回复量         | 2/3/4/5/6                         | 1/1.5/2/2.5/3          |
| 受击后第一口       | 第 10 秒                          | 第 20 秒               |
| 满级持续回复上限   | 1 生命/秒                         | 0.25 生命/秒，降低 75% |
| 三级自动补盾间隔   | 90/75/60 秒                       | 180/150/120 秒         |
| 空盾时普通受击     | 仅刷新 8 秒安全期，可保留补盾进度 | 全部补盾进度清零       |
| 击杀掉落盾最短间隔 | 20 秒                             | 45 秒                  |

护盾挡住的有效攻击也会打断两种恢复。无敌期间被忽略的碰撞不算有效受击；自动盾只补一层，持有盾时不积攒进度，拾取盾也清空进度。满血不储存回血；死亡不能被自动回血或自动盾撤销。暂停、升级选择和商店不推进模拟计时。

原有爱心和随机满血卡保留。回血参数、强化描述与战场倒计时读取同一配置，客户端与服务端回放执行相同规则。新旧规则成绩隔离，原有本地钱包与已购强化保留。

## 固定种子对比

运行 `node scripts/check-farm-balance.mjs --recovery` 可复现修改后的样例。修改前从提交 `5854d1e` 的战斗规则采样，使用相同脚本输入。

- 种子：2026-10-01、02、03、04、07、17，分别覆盖慢板、急板、重甲、短弓、丰收、密潮。
- 强化：无强化；低强化（生命 3、护甲 1、回血 1、护盾 1）；八项全部满级。
- 输入：原地站桩、正弦绕圈、躲避最近怪物。站桩仍自动攻击、选择升级和使用满能量音浪爆发。
- 无注入经验、免费装备或额外无敌。意向乐器为 echo，开局未抽到时按现有策略采用实际可选乐器；并非十种构筑的完整覆盖。
- 每组 6 局，上限 600 秒，合计 54 局。到达上限仍存活属于截尾结果，不能当作最终死亡时间。

| 输入 | 无强化：修改前→后仍存活 | 低强化：修改前→后仍存活 | 满强化：修改前→后仍存活 |
| ---- | ----------------------- | ----------------------- | ----------------------- |
| 站桩 | 2/6 → 1/6               | 3/6 → 2/6               | 6/6 → 6/6               |
| 绕圈 | 2/6 → 1/6               | 4/6 → 1/6               | 6/6 → 5/6               |
| 躲避 | 3/6 → 3/6               | 3/6 → 4/6               | 6/6 → 6/6               |

满强化在 600 秒内仍然很强，所以另做 6 局满强化站桩、1800 秒上限的长局。两版六局都实际死亡，结果如下，均非到达时限：

| 词缀 | 修改前死亡秒数 | 修改后死亡秒数 | 护盾实际挡伤次数：前→后 |
| ---- | -------------- | -------------- | ----------------------- |
| 慢板 | 669.125        | 797.9375       | 24 → 17                 |
| 急板 | 870.625        | 958.75         | 18 → 14                 |
| 重甲 | 946.8125       | 870.625        | 41 → 19                 |
| 短弓 | 794            | 628.125        | 27 → 14                 |
| 丰收 | 649.25         | 740.5625       | 26 → 16                 |
| 密潮 | 1425.5         | 1420.6875      | 49 → 29                 |

护盾挡伤次数在六个长局中都减少。存活时间并不逐局单调下降：受伤会改变爱心掉落与满血卡的实际回复量，恢复事件还会影响后续战斗序列。脚本分别记录爱心加自动回复总量、满血卡实际回复量、受伤量和护盾挡伤次数；不能把总回血量增加解读为自动回血变快。

这些样例没有出现满强化站桩无限存活，但不能证明所有种子、所有构筑或真人体验都已平衡。后续应依据实际玩家的死亡时间和恢复来源调整，不把降低存活时间作为每个单一样例的硬性目标。

## 自测

新增覆盖各级整数与半点回血、回复上限、20 秒首口与 12 秒周期、普通受击清空完整补盾进度、无敌忽略攻击、同帧拾取优先、45 秒掉落边界，以及满防御加三层盾仍无法抵消每秒一次普通攻击。

完整测试 35 个文件、229 项通过；`npm run lint`、`npm run build`、`npm run format:check` 与 `git diff --check` 通过。真实死亡回放与新版本榜单隔离继续由现有服务端测试验证。
