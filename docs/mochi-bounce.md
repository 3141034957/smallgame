# 小兔弹弹乐

首页改为音乐弹射玩法：拖住小兔往下拉，松手反向弹射；直接点击会用默认角度和力度弹出。每次发射可以瞄准角度、控制力度，借墙壁与底部软垫反弹。碰撞乐器产生声音、分数与音符动效。没有白块音轨、路线点击任务或需先阅读的资源系统。

## 核心循环与反馈

一局三次弹射，每发补满 21 个声音目标。普通目标基础 70 分，金色目标 150 分；粉色炸花击中后会触发 111 世界单位以内未击中的目标，其他炸花可继续连锁。每个目标在一发内只能得分一次。连击每四次提高倍率，上限五倍；6、12、18 连击各触发一次合奏爆发并奖励 400 分。

底部软垫每发自动反弹两次，让首次点击有连续碰撞机会。角度与力度改变真实碰撞路线，花园不自动吸附小兔，也不虚构命中或排名。2026-10-04 第一个花园：20°、95% 力度可得到 20 连击、6,480 分；40°、95% 力度得到 3 连击、210 分。不同日期、后续两发的布局不同，需要观察炸花位置、尝试反弹角度。

正反馈包括即时合成乐器声音、音符/分数弹出、移动轨迹、连击倍率、合奏和支持设备上的轻震动。结算显示本机新纪录或离新纪录的实际差距，支持直接重开、试听刚才碰撞形成的合奏、生成同一日期的朋友挑战链接。新纪录按当前设备当日最佳判断；玩家姓名与身份沿用软糖乐队存档，不假造参与人数或超越比例。

## 物理、排行榜与持久化

共享纯规则在 `src/features/bounce/rules.mjs`。输入量化为整数角度 -65°～65°、力度 45～100，每发固定起点。物理使用固定 1/120 秒步长，包含圆形碰撞、重力、墙壁与两次底部反弹，每发最多 8 秒。浏览器预计算轨迹，再按画面时间播放；暂停、低帧率和切换标签页不改变已确定的碰撞结果。北京时间的日期生成三发地图，规则版本和日期分隔每日榜。

- `GET /api/bounce/leaderboard?day=2026-10-04&playerId=...`
- `POST /api/bounce/score`：`{ day, shots: [{ angle, power }, ...], score, playerId, name }`

服务端要求完整三发、合法范围、有效日期和身份，重新计算每次物理碰撞、炸花连锁、倍率与合奏奖励，再比较客户端分数。客户端只传总分、改力度到范围外或提交未完成局均不能上榜。匿名客户端仍能构造合法的最佳输入，此机制是轻量重放校验，不是账号验证或对求解器的实时防作弊。

复用 SQLite 的 `melody_scores`，使用独立键 `bounce:v1:<日期>` / `bounce`，不改动其他游戏的排行数据。每玩家每日期保留最佳，展示前 50 名与个人排名。排序为总分、击中比例、最高连击、首次达成时间。提交后显示真实名次，榜内有上方玩家时提示再拿多少分能超过相应名次。

本机单独保存最近 30 天的最佳分与最高连击。排行榜断线可以重试；存档失败保留本次内存成绩并提示，仍能提交排行榜。分享链接只带日期和目标分数，不会自动发布被邀请者或朋友的成绩。

## 界面与兼容

默认 `#/`、`#/bounce` 进入弹弹乐；`#/island` 保留声音探险；`#/rhythm` 保留节奏舞台；原花房、Mochi Cat、商店不变。原来的根路径 `island` / `route` 邀请和 `song` / `mix` 邀请继续进入对应玩法。

手机支持指针捕获的拖动与轻点，拖出花园仍可正常松手发射；电脑支持左右键改变角度、上下键改变力度、空格/回车发射。切换标签页会暂停；返回后手动继续。帮助和暂停对话框提供键盘焦点控制，减弱动画设置关闭闪动、轨迹和震动反馈。植物、角色、花园为现有 SVG/CSS 和代码绘图，音乐沿用 Web Audio 合成，不增加依赖或外部音乐素材。

## QQ 音乐方向：弹一首歌给你（2026-10-04）

这是面向 QQ 音乐听歌、互动分享场景的功能原型：建议入口放在歌曲播放页的「弹给朋友」。用户给喜欢的歌加一段自己的伴奏，生成演奏卡，朋友打开先听伴奏，再用自己的演奏回应。

当前首页默认进入三幕演奏；`#/bounce?mode=classic` 保留经典版及原有排行榜。前奏是花园，副歌低重力且炸花能带响两个同音色目标，尾奏有两个声音传送门。四个乐手分别有回声、撞墙鼓浪、两次穿透、三色和声奖励，选择会影响真实碰撞和得分。每一幕仍是一拉一松的操作。

支持在「换首喜欢的歌」填写歌名、QQ 音乐 HTTPS 分享链接和选择本地音频。本地音频通过浏览器播放器试听，不上传；暂停、静音会同步控制它。歌曲链接仅用于原曲跳转，不自动读取歌曲信息或下载。尚未接入 QQ 音乐账号、曲库 API、歌词、歌曲结构分析或 AI 编曲服务；游戏碰撞产生的伴奏是 Web Audio 合成音色，也没有声称分享卡含有原曲。

分享链接带 `mode=tour`、日期和三次量化弹射（角度、力度、乐手）。接收方重新计算成绩和音符，可试听发送者的伴奏；没有本地音频或音频数据上传。歌曲标题及原曲链接随分享传递。未知乐手和非法弹射参数会被拒绝。

新榜使用 `bounce:v2:tour:日期`，与经典 `bounce:v1:日期` 分开；后端重演三幕并校验分数。所有歌曲都使用同一天同一套舞台，音频不会改变计分，避免自选歌曲影响公平性。本机最佳纪录也分开保存。匿名排行榜不是 QQ 音乐账号榜。

验证：84 个测试通过，覆盖角色能力、传送门、无重复碰撞、奖励总分、分享记录重演、新旧排行榜隔离及非法链接。生产构建和 lint 通过；浏览器另行验证三幕结束、角色切换、分享试听及成绩提交。本次修改未同步到 Ubuntu 公网服务器。

浏览器实测：20,190 分、21 连击、9 次技能、3 次传送，测试数据库上榜及分享接收页正确。音频文件导入的自动化验证因 Chrome 扩展未获本地文件权限而未完成；需要人工选择音频再检查播放。
