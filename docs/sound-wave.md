# 音浪连连：连续操作的音乐消除试玩

用户反馈弹射版不好玩后，首页核心改为 45 秒连线消除。目的是验证「连续做选择、立刻得到声画反馈」能否改善体验，不以功能数量或自动化测试证明好玩。

## 操作与决策

按住并滑过相邻的同色动物，横竖斜都可，至少三个后松手消除。向前一格滑动能撤回选择。第一次触碰开始倒计时，开局最底排同色用于直接上手。无须踩准节拍。

- 三连立即开唱、消除和补位；消除音色由所选动物决定。
- 六连及以上留下十字唱片，可单独点爆整行整列。
- 十连及以上留下同色唱片，可点爆当前全部同音色动物。
- 爆炸可连锁引爆其他唱片，每个目标只结算一次。
- 消够 24 个音符点亮合奏按钮，玩家选择何时释放；清除数量最多的音色并加分，能量归零。
- 三秒内连续消除保持连唱，倍率每三次增加，最高五倍。超过三秒重新从一次连唱开始。
- 长连、快消和储存唱片之间存在选择；提示可指出合法三连。

键盘支持方向键移动、空格/回车选取、在已选终点再次按键确认，或使用「开唱」按钮。Esc 清空选择。关闭页面、切后台或打开排行榜会停音乐并暂停，恢复后保留剩余时间；重新开始会清空当前记录。

## 音乐和 QQ 音乐场景

原创伴奏使用 Web Audio，112 BPM，和弦与低音持续播放；选择路径会即时演奏，消除时动物乐队响应。消除顺序决定音色和五声音阶旋律，结算可回听最后一段。适合验证歌曲播放页附加互动入口的概念。尚无 QQ 音乐账号、曲库或歌曲分轨接入；当前伴奏不是 QQ 音乐原曲，没有 AI 音频分析服务。

## 排行榜和兼容

`#/wave` 以及无旧邀请参数的首页进入新版。`#/bounce` 保留上一版；原有节奏、探险、Echo 分享继续可用。新版分享邀请使用日期和目标分，好友得到同一初始音符池。它不传递演奏录像或原曲。

`src/features/wave/rules.mjs` 是前后端共用的纯逻辑。每日种子生成同一初始棋盘，重演每次清除与补位；无合法组合时保证生成一组三连。动作有虚拟游戏时间和路径下标或合奏标记。后端拒绝重复节点、不邻接、跨音色、未充能合奏、越界时间、过快动作及伪造分数。每局不超过 250 次动作。暂停时游戏时间不增加。匿名输入重演能校验操作和结果一致，不能保证客户端时间可信，也不是完整的防作弊或 QQ 账号系统。

独立 `wave:v1:日期` 榜保留每人最高分；同分按清除数量、最高连唱和达成时间排序。QA 使用临时数据库，不修改生产成绩。

## 验证

全项目 92 个测试通过；新增覆盖日棋盘、合法/非法路径、重力补位、唱片生成与连锁、主动合奏、倍率衰减、整局重演和成绩 API。构建与 lint 通过。手机浏览器已实测一笔六连、点爆十字唱片、回退重连、七连充能、主动合奏与暂停。自动化检查验证机制正常；体验吸引力仍需真人试玩评价。

当前仅本地试玩，尚未同步到 Ubuntu 公网服务器。

端到端实测完成：45 秒结束后得到 2,375 分、1 次唱片爆炸、1 次主动合奏，测试数据库返回第 1 名；回听按钮和携带日期/目标分的分享链接正常。测试用操作间隔较长，未用这局数据判断游戏乐趣或玩家留存。
