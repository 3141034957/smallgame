# 流派与组合技

日期：2026-10-07。本文数据以 `src/features/farm/schools.mjs`（流派与组合技数据层）和 `src/features/farm/rules.mjs`（`TALENTS` / `RECIPES` / 战斗与回放）的实际实现为准。

这是 [怪潮乐队历险记](music-farm.md) 局内构筑的使用说明：把「拿什么乐器 → 配什么芯片 → 什么时候进化 → 凑哪个组合技」讲清楚。成长路线的整体规划见 [玩家成长规划](player-growth-plan.md)。

## 1. 什么是流派

**一件核心乐器 + 一件专属芯片 + 两者都升到 Lv.5 后的进化形态 = 一个流派。**

- **核心乐器（weapon）**：决定主要攻击方式，由乐队成员或辅助合成器提供。开局从十种攻击里随机发三项。
- **专属芯片（chip）**：每件乐器都有唯一对应的芯片。芯片首先是**通用基础属性**，对每一种攻击都生效，与哪件乐器无关；配对满级后的进化只是额外的套装效果。
- **进化形态**：乐器与芯片**双方都到 Lv.5 时自动进化**，攻击变化即时生效，不需要额外抽卡（判定见 `rules.mjs` 的 `evolved()`）。

槽位与上限：一局最多携带 **5 件乐器 + 5 件芯片**；乐器与芯片各自最高 **Lv.5**，因此最多 50 次构筑强化，其余升级用于回血或尾声成长卡。槽位满了之后不再发新的乐器或芯片，只升级已有构筑；恢复满血卡不占槽位。长局中可以凑齐多件终极乐器。

流派进度分四层，帮助页和升级页按这个层数提示你还差多少：

| 层数 | 含义                     |
| ---- | ------------------------ |
| 0    | 还没接触这件乐器或芯片   |
| 1    | 已拿到核心乐器（或芯片） |
| 2    | 乐器与芯片齐备，开始成长 |
| 3    | 其中一件已经满级         |
| 4    | 已进化成终极形态         |

## 2. 十个流派一览

流派名与定位来自 `schools.mjs` 的 `SCHOOL_DEFINITIONS`，乐器名、芯片名与进化名来自 `rules.mjs`。

| 流派     | 风格     | 核心乐器（成员）        | 专属芯片                       | 进化形态   | 定位                                 |
| -------- | -------- | ----------------------- | ------------------------------ | ---------- | ------------------------------------ |
| 鼓组流   | 连锁爆破 | 🥁 鼓手咚咚             | 共鸣音箱（所有攻击范围 +）     | 雷霆鼓组   | 击杀引爆周围怪群，被波及的怪持续掉血（余音），清场最快，但怕散兵 |
| 吉他流   | 环绕音刃 | 🎸 吉他手弦弦           | 节拍器（攻击节奏更快）         | 星环电吉他 | 音刃绕身护体，输出平稳还能挡下弹幕   |
| 贝斯流   | 贯穿收割 | 🎻 贝斯手阿低           | 拾音器（经验金币从更远处飞来） | 黑洞贝斯   | 低音光柱与黑洞成片收割，经验自己涌来 |
| 主唱流   | 自动追踪 | 🎤 主唱啾啾             | 安可徽章（金币经验 +、暴击）   | 星雨麦克风 | 高音箭雨自己找怪，站着也能打满全场   |
| 键盘流   | 环形冲击 | 🎹 键盘手叮当           | 延音踏板（残留与减速更久）     | 银河键盘   | 星浪推开身边怪群，被围住时的解围手段 |
| 长笛流   | 残留音阵 | 🪈 长笛手呼呼           | 延迟效果器（残留更久更密）     | 回音长笛阵 | 走过的路变成持续伤害区，走位就是输出 |
| 萨克斯流 | 冲刺控制 | 🎷 萨克斯阿鸣           | 弱音器（范围 +、击退更远）     | 金焰萨克斯 | 号角波撞飞并拖慢一排怪，控场能力最强 |
| 采样台流 | 音爆连锁 | 🎛️ 节拍鳄小绿           | 触发器（布设更快更密）         | 爆音采样台 | 埋下的采样延时炸开，适合绕圈拉怪     |
| 唱盘流   | 回响弹幕 | 💿 打碟机哔哔           | 唱针（所有攻击伤害 +）         | 黑胶风暴台 | 宽音刃绕身并弹射连锁，怪越密越强     |
| 合成器流 | 扇形棱镜 | 🎚️ 辅助合成器（非成员） | 琶音器（范围 +、扇形更宽）     | 棱镜合成器 | 扇形音浪穿透一排怪，方向感决定上限   |

辅助合成器不是乐队成员，但同样是一件核心乐器，与琶音器配对后进化成棱镜合成器。每一个流派进化后的具体变化写在 `RECIPES` 里（例如鼓组流是「爆破范围大幅扩张，连锁伤害翻倍」，吉他流是「八道音刃环绕，触碰伤害翻倍」）。十种乐器的攻击细节见 [怪潮乐队历险记](music-farm.md) 的「乐队成员、装备、终极乐器」一节。

## 3. 跨流派组合技

组合技是**跨流派的额外增益**：前提达成后自动生效，**不占乐器和芯片槽位，也不消耗升级次数**。前提只看进化形态（`evolved()`），与芯片是否还在升级无关。

| 组合技      | 前提                      | 效果                                                     |
| ----------- | ------------------------- | -------------------------------------------------------- |
| 🌀 共振风暴 | 鼓组流 + 合成器流都进化   | 连锁爆破与扇形音浪**伤害 +15%**、**范围 +8%**（只加爆破伤害，余音不吃这个加成） |
| 🕳️ 低音陷阱 | 贝斯流 + 长笛流都进化     | 残留音符（长笛音阵）**伤害 +25%**，掉落**拾取范围 +20%** |
| 🎸 金属回响 | 吉他流 + 唱盘流都进化     | 吉他与唱盘的**音刃伤害各 +15%**，回响弹**伤害 +50%**     |
| 🌟 星海合唱 | 主唱流 + 键盘流都进化     | 环形冲击（星浪）**伤害 +20%**，追踪音雨**伤害 +15%**     |
| 🎷 铜管狂潮 | 萨克斯流 + 采样台流都进化 | 号角冲刺波**伤害 +20%**，音爆采样**伤害 +25%**           |
| 🎆 全场安可 | 任意 **3 个**流派完成进化 | **全部伤害 +8%**（余音除外），掉落**拾取范围 +15%**       |

数值均为「在既有数值上乘一个 ≥1 的系数」，组合技不发明新的攻击机制，因此既有平衡回归与逐帧重放都不会被破坏。多个组合技命中同一个增益键时**加算**到同一个基准上（`comboModifiers`）。

**例外：鼓的余音**。余音是被鼓的爆破波及后挂在怪身上的持续掉血，走独立管线，只跟鼓等级走（4 秒、每 1 秒一跳、每跳 = 鼓等级 ×（已进化 ? 2 : 1），数值**待试玩校准**）。它不吃暴击、不吃局内倍率、不加永久强化伤害，也**不受任何组合技加成**——🌀 共振风暴加的是爆破伤害，不是余音。详细口径见 [怪潮乐队历险记](music-farm.md) 的余音表格。

要点：

- 五个配对组合技把十个流派两两配对，**互不冲突**；理论上五个可以同时生效，前提是槽位与升级次数够用。
- **全场安可**不挑流派，只要凑够 3 个进化就生效，是「先凑数量」路线的兜底奖励。
- 帮助页会用 `comboProgress()` 区分「已达成」和「差一点」：前者列出已生效的组合技，后者在两个流派各自已经有乐器或芯片满级（或全场安可只差一个进化）时提示你下一步拼什么。

## 4. 推荐构筑路线

下面三条路线都只用**两个流派**（4 个槽位：2 乐器 + 2 芯片），剩下 3 件乐器 + 3 件芯片留给补位乐器或回血卡。路线里的时间来自 `node scripts/check-farm-balance.mjs` 的自动模拟，真人手感会有差异。

### 路线一：主唱流 + 键盘流 —— 🌟 星海合唱（最省心）

1. **开局拿主唱啾啾**（高音箭雨自动追踪，不需要瞄准）。开局发牌没有主唱时，先拿任意乐器，第一次升级再转。
2. **前 30 秒只喂主唱与安可徽章**：安可徽章同时给暴击和收益，越早拿越划算。
3. **约 27 秒进化出星雨麦克风**（一次追击八只怪），这是本局第一个成型点。
4. 之后补键盘手叮当 + 延音踏板：键盘的环形冲击负责把贴身的怪推开，正好补上主唱缺的解围能力。
5. 键盘也满级后自动触发**星海合唱**；若这时已经凑到第三个进化形态，**全场安可**同时生效。

适合第一次玩：全程不用瞄准，输出和解围都有自动兜底。

### 路线二：鼓组流 + 合成器流 —— 🌀 共振风暴（清场最快）

1. **开局拿鼓手咚咚**。连锁爆破在怪堆里收益最高，早期怪潮密集时升级最快；爆破还会给命中的怪挂上余音，让它离开爆破范围后继续掉血。
2. 优先把鼓与共鸣音箱同时推到 Lv.5：共鸣音箱的范围加成同时喂给爆破半径和合成器的扇形音浪（余音伤害只跟鼓等级走，范围芯片不加成）。
3. **约 27 秒进化出雷霆鼓组**，爆破半径大幅扩张，余音每跳伤害同时翻倍，此时可以主动往怪多的方向钻。
4. 第二个流派选辅助合成器 + 琶音器：扇形音浪穿透一排，补上鼓打不到的远处怪。
5. 合成器满级触发**共振风暴**，爆破与音浪同时再涨 15% 伤害、8% 范围；注意它只加**爆破伤害**，余音不受这 15% 影响。这条路线清怪数量最高，但鼓是近身打法，要留意重装音箱的砸地预警。

### 路线三：吉他流 + 唱盘流 —— 🎸 金属回响（自保最强）

1. **开局拿吉他手弦弦**。旋转音刃绕着你飞，还能挡下飞来的弹幕，对噪音怪和 Boss 弹幕最友好。
2. 优先吉他 + 节拍器（攻速），音刃数量随等级增加。
3. **约 27 秒进化出星环电吉他**（八道音刃环绕，触碰伤害翻倍），此时基本不用躲普通小怪。
4. 第二个流派选打碟机哔哔 + 唱针：唱针给所有攻击加伤害，黑胶风暴台的四片宽音刃与音刃吉他叠成双层环绕。
5. 唱盘满级触发**金属回响**，回响弹伤害 +50%。这条路线对操作要求最低，适合先熟悉 Boss 节奏。

### 什么时候进化、什么时候换路线

- 首次升级约在 **0.125–6.25 秒**（开局附近本来就有可击败的小怪），首次进化约在 **19–27.8 秒**（中位 **27.7 秒**）。
- 因此**第二个流派通常在 60 秒后才成型，组合技一般落在 90–180 秒之间**。前 30 秒不要为了凑组合技去拿第三件乐器，先把第一对推满。
- 槽位（5 乐器 + 5 芯片）在满配前不会拒绝新乐器，但每拿一件新乐器都会稀释已有流派的等级。**两个流派 + 一到两件补位乐器**是最稳的配比。
- 想同时吃多个组合技，就按上面的两两配对挑流派；临时拿到的第三件乐器如果能凑到第三个进化，顺手也能触发**全场安可**。

## 5. 平衡验证

复现命令：`node scripts/check-farm-balance.mjs`（固定种子，最多模拟 300 秒，不注入生命、装备或经验）。

| 指标               | 最小   | 中位    | 最大    |
| ------------------ | ------ | ------- | ------- |
| 首次升级时间（秒） | 0.125  | 6.125   | 6.25    |
| 首次进化时间（秒） | 19     | 27.6875 | 27.8125 |
| 存活时间（秒）     | 76.75  | 300     | 300     |
| 最终角色等级       | 22     | 73      | 77      |
| 本局拾取金币       | 11,739 | 134,286 | 206,656 |

- 60 局样本（6 种每日词缀 × 10 件意向乐器）**全部完成至少一次进化**。
- 脚本的开局发牌不因意向乐器而改变，模拟都会转向实际发到的乐器，因此同一天下的 10 条意向配置产出同一条轨迹：**60 个样例不等于 60 个独立构筑**。
- 6 条绕圈主唱路线（无永久强化）在六种词缀下**全部存活到 300 秒上限**，等级 63–77，单局进化 4–5 组，金币 88,754–214,745。存活 300 秒的结果属于**截尾数据**，不能解释为最终死亡时间。
- 组合技不改变首次升级（0.125–6.25 秒）与首次进化（19–27.81 秒）的时间，只让中后期的等级与金币小幅提高（最终等级上限 76 → 77，金币中位 132,630 → 134,286）。

这些是自动模拟的节奏回归结果，不代表真人通关率或设备手感。组合技的增幅一律只放大既有数值，且数值较小（单个增益 8%–50%），目的是让成熟构筑更强，而不是改变上面的成长节奏。

真机冒烟（2026-10-07）：构造一局鼓组流 + 合成器流 + 主唱流 + 键盘流的战绩（共振风暴、星海合唱、全场安可同时生效，502 秒、8036 帧、4,076,780 分），注册账号后提交 `POST /api/farm/score`，服务端完整回放校验**通过（HTTP 200）**，说明组合技已进入共享规则且前后端结果一致。
