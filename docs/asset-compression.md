# 游戏素材压缩

游戏实际使用的九张乐队角色和七张怪物图已由 PNG 改为高质量透明 WebP，总体积从 **22.72 MB 减到 4.23 MB（减少 81.4%）**。`public/` 只保留运行图，原稿位于 `design-assets/band-lineup/` 和 `design-assets/monsters/`，不会被 Vite 复制进发布包。海报、宣传图和生成原稿继续保留原始质量。

## 压缩设置与效果

- 保留原尺寸：角色 1254 × 1254，怪物 1024 × 1024；不裁切、不缩小。
- WebP 色彩质量 95，使用 sharp YUV 转换减少细线和色彩边缘的损失。
- 透明通道质量 100，无损保存半透明轮廓；移除无关元数据。
- 16 张图逐张解码对比：尺寸一致，透明通道每个像素一致；在背景上合成后的 RGB PSNR 均超过 40 dB，并检查浅色和深色背景下的显示效果。色彩采用轻度有损压缩，原稿仍可用于重新导出。
- 游戏中的 160px 角色画布、192px 怪物画布及商店的显示尺寸不变。场景背景由代码生成，没有需要转换的外部背景图片。

## 更新素材

先更新 `design-assets/` 下的同名 PNG，再运行：

```sh
# macOS 安装编码工具（只在导出素材时需要，部署和浏览器运行不需要）
brew install webp
npm run assets:optimize
```

脚本从共享角色和怪物清单读取路径，采用上述固定设置生成 `public/assets/` 下的 WebP，并报告压缩前后体积。新增角色或怪物时，清单里的 `image` 应使用 `.webp`，同时提供对应目录的 PNG 原稿。

角色商店、排行榜、玩法图鉴和战斗渲染共用同一组图片路径。自动检查覆盖图像格式、透明标记、原尺寸、总素材体积上限，以及生产服务器的 WebP MIME 和原样传输，避免发布时错图、丢失透明效果或重复压缩。
